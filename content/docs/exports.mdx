## How does Ease export CSS linear() springs?

Ease solves continuous second-order differential equations for physical mass, stiffness, and damping, then applies Ramer-Douglas-Peucker quantization to sample the resulting waveform into an optimized CSS linear() timing function that executes entirely on the browser compositor thread with zero JavaScript animation overhead.

## Which animation frameworks are supported?

Ease exports production-ready animation definitions across four primary developer ecosystems: native CSS transitions and linear() springs, Tailwind CSS v4 custom theme timing functions, Motion (Framer Motion) transition objects with exact physics parameters, and GSAP CustomEase cubic-bezier spline strings with companion duration attributes.

## Lossless Share URLs (`#hash`)

Every curve and spring crafted in Ease encodes its entire state losslessly into the browser URL hash fragment:

- Zero database dependencies or backend latency.
- Instant, immutable sharing with team members, designers, and pull requests.
- Clicking a share link immediately hydrates the curve into the active studio workspace.
