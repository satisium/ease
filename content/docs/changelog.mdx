## 0.3.0

### Minor Changes

- d58da2b: Implement the Animation Sniffer Engine, Universal DOM Applicator, and Adaptive Kinetic Role Motion Guide:

  - Discovers animated elements, CSS transitions, keyframes, and WAAPI animations in any stage component.
  - Decomposes multi-property transforms (translateY, scale, rotate) into discrete kinetic channels with automated collision consolidation.
  - Dynamically transmits detected channels over the isolated postMessage bridge (`SNIFFER_DETECTED_CHANNELS`).
  - Dynamic squircle Channel Strip in Center Stage Audition Toolbar displaying detected kinetic channels.
  - Right Flank Motion Guide dynamically adapts its architectural advice, target durations, and recommended curves to the detected Kinetic Role (`Atmospheric Scrim`, `Focal Surface Lock`, `Tactile Press`, `Edge Sheet Slide`, `Track Pagination`).
  - Center Stage Audition Toolbar UI/UX overhaul: explicit semantic `[ ↓ Entrance ]` and `[ ↑ Exit ]` segmented control with reactive Channel Strip coupling and full ARIA semantics.
  - Decoupled studio curve selection from playback: browsing curves and switching phase tabs is calm and passive; auditions trigger only on explicit user intent (`Space`, `R`, scrubber, transport buttons, or in-stage triggers).
  - Live kinetic curve evaluation engine in `/stage`: fixed priority resolution loop so live selected curves immediately evaluate across the live stage DOM during playback.
