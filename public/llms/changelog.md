# Changelog

> Product releases and kinetic milestones for Satisium Ease.

## v1.0 — Studio Release

### Highlights

- **21 Production UI Habitats:** Interactive audition environments categorized into Overlays (Modals, Sheets, Drawers, Tooltips), Controls (Switches, Sliders, Pickers, Segmented Bars), Disclosure (Accordions, Flyouts, Tabs, Menus), and Landing stages.
- **Default 4-Track Primitives X-Ray:** First-class multi-track kinematics (Position, Scale, Rotation, Opacity) rendered directly on center stage with Duration Integrity synchronization.
- **Newsreader Editorial Typography:** Satisium brand typographic refinements featuring high-contrast serif accents and calibrated Major Second text rhythm.
- **Interactive Toolbar Track Reset:** Instant channel-level reset and scrub targeting in the studio timeline console.
- **Mobile Desktop-Handoff Guard:** Responsive card informing mobile visitors of the desktop-class (1024px+) workstation requirement while maintaining access to documentation.
- **Open-Source Launch:** Public release under the permissive MIT license with complete headless core architecture and community support on Discord.

## v0.11 — Liquid Studio Motion

- **100% Opaque Stage & Flank Slides:** Fluid GPU-accelerated mode transitions with edge progressive blur vignettes and zero substrate bleed.
- **Unified Spring Pills:** Cohesive sliding indicator geometry across Audition Toolbar, Preset Catalog, and Curve Editor.
- **NumberFlow Rolling Telemetry:** Smooth rolling numeric readouts for velocity, overshoot, duration, and parameter scrubbers.
- **Channel Dropdown in Preview Mode:** Direct per-channel curve inspection and override controls in Preview Theater.

## v0.10 — Compare Mode & Persistence

- **Side-by-Side Curve Duel Theater:** Mode 3 benchmarking environment to evaluate competing curves under synchronized real-time playback.
- **Wall-Clock Scrubber:** High-precision timeline transport with continuous scrubbing, loop delays, and multi-speed playback.
- **Single-Ease 4-Framework Exporter:** Universal production code generation for CSS cubic-bezier & linear(), Tailwind v4, Motion, and GSAP CustomEase.
- **Automatic v3 Local Persistence:** Instant localStorage state preservation for custom curves, variants, and audition preferences.
- **Studio Command Palette (`⌘K`):** Fast keyboard-driven discovery across 61 presets, habitats, modes, and documentation pages.

## v0.9 — Customize Canvas & Headless Core

- **1:1 Tactile SVG Canvas:** Interactive Bézier handle manipulation and analytical ODE spring parameter tuning on a 4×4 coordinate grid.
- **2-Tier Git Curve Branching:** Non-destructive curve iteration supporting Root curves, committed Variants, and uncommitted Draft edits.
- **61 Canonical Presets:** Curated library of motion curves spanning Material, Apple, Tailwind, CSS standards, and physical springs.
- **Pure Zero-React Core:** Decoupled headless mathematical solvers, ODE differential evaluators, and Zustand stores with zero DOM dependencies.
