# Overview & Quickstart

> Satisium Ease is an interactive cubic-bezier and analytical spring physics studio for design engineers.

## What is Satisium Ease?

Satisium Ease is an interactive kinetic sandbox and production motion curve studio for frontend engineers and design technologists. It enables developers to author, calibrate, and duel cubic-bezier transitions and analytical spring physics on authentic UI habitats before exporting clean code to modern frameworks.

## How does Ease work?

Ease operates through a cohesive three-mode kinetic lifecycle: audition curves on production UI components in Preview, inspect differential spring equations and control points in Customize, duel staged contenders side by side in Compare, and export compositor-accelerated CSS and framework tokens instantly with Command-E.

## The Three-Mode Workflow

The studio workstation is organized into three connected interactive modes:

1. **Preview Mode (`1`):** Audition and calibrate timing curves on real UI habitats (Modals, Navigation Drawers, Dropdowns, Cards, Badges, and Switch Toggles) under authentic interactive constraints.
2. **Customize Mode (`2`):** Directly sculpt control handles on the high-precision cubic-bezier canvas or dial in physical mass ($m$), stiffness ($k$), and damping ($c$) parameters with real-time velocity curves and overshoot telemetry.
3. **Compare Mode (`3`):** Stage candidate curves into the duel queue and play them simultaneously side-by-side to evaluate perceptual differences, arrival times, and settle durations under identical conditions.
4. **Universal Export (`⌘E`):** Generate one-click production code for native CSS, Tailwind CSS v4, Motion, and GSAP CustomEase, or copy a lossless `#hash` URL.

## The Duration Integrity Law

When animating complex multi-channel UI components (e.g. dialog scale, translation, and background scrim fade), applying a uniform duration causes artificial visual stiffness. Ease enforces the **Duration Integrity Law**: each kinetic channel preserves its calibrated temporal proportion, ensuring that large spatial translations complete with appropriate inertia while micro-scale transforms resolve swiftly.

## Studio Keyboard Shortcuts

Ease provides complete keyboard navigation across all studio operations:

| Shortcut                          | Action                                              | Destination / Scope |
| :-------------------------------- | :-------------------------------------------------- | :------------------ |
| <Kbd>Space</Kbd>                  | Toggle Play / Pause playback                        | Center Stage        |
| <Kbd>R</Kbd>                      | Reset playhead to `0ms` and replay                  | Center Stage        |
| <Kbd>I</Kbd>                      | Interrupt active motion and reverse                 | Center Stage        |
| <Kbd>L</Kbd>                      | Toggle infinite playback looping                    | Timeline Console    |
| <Kbd>S</Kbd>                      | Solo active channel track                           | Timeline Console    |
| <Kbd>T</Kbd>                      | Toggle Timeline Console drawer                      | Master Console      |
| <Kbd>C</Kbd>                      | Stage active curve into Compare queue               | Compare Flank       |
| <Kbd>1</Kbd>                      | Switch to Preview Mode                              | Right Flank         |
| <Kbd>2</Kbd>                      | Switch to Customize Mode                            | Right Flank         |
| <Kbd>3</Kbd>                      | Switch to Compare Mode                              | Right Flank         |
| <Kbd>⌘E</Kbd> / <Kbd>Ctrl+E</Kbd> | Open universal Export dialog                        | Studio Shell        |
| <Kbd>⌘K</Kbd> / <Kbd>Ctrl+K</Kbd> | Open global Command Menu                            | Global Palette      |
| <Kbd>Esc</Kbd>                    | Dismiss modal, exit sub-level, or return to Preview | Universal Dismiss   |
